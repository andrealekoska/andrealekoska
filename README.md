## Andrea Lekoska

Graduate engineer in Information Technologies and Computer Engineering, Faculty of Computer Science and Engineering, Ss. Cyril and Methodius University in Skopje. I work in Java and Spring Boot, Python and SQL.

**Research.** My paper comparing four approaches to sentiment analysis of tourist reviews from Ohrid was accepted as a full paper at ICT Innovations 2026 and will be published by Springer in the Communications in Computer and Information Science series. I designed the study and built the dataset of 1,060 reviews by hand, and released it publicly.

→ [ohrid-sentiment-analysis](https://github.com/andrealekoska/ohrid-sentiment-analysis)

**From a paper to something that runs.** I took that model out of the notebook and put it behind a Spring Boot REST API, running next to a Python service, containerised with Docker and covered by tests, so that a result reported in a paper can be called by other software.

→ [ohrid-sentiment-api](https://github.com/andrealekoska/ohrid-sentiment-api)
